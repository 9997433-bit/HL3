## 0. 产品定义与定位

| 产品 | 一句话 | 对标（仅公开功能面） |
|------|--------|----------------------|
| **HL3-2D** | 单相机平面 DIC 全链路工作站：全场位移/应变 + UQ 默认输出 + Python-first + 跨平台 | VIC-2D 8 |
| **HL3-3D** | 双目（架构上 N 目）立体 DIC 测量平台：标定→匹配→三角化→曲面应变→FEA 闭环，全链协方差传播 | VIC-3D 11 |

两款产品共享 `hl3-core` 内核（相关器、应变、UQ、HDF5 数据模型、Python API）；HL3-3D 额外启用标定、极线匹配、三角化、曲面应变模块（R1-F1 §2.2 ADR-1，R1-O1 §4.1 边界）。**超越的对象是整条测量链**（采集–标定–相关–应变–可视化–Python–报告–实时），不是单个相关器 demo（ROUND1_BRIEF §1 收敛结论）。

**范式主张**（R1-F1 §1.3）：VIC 是封闭桌面计量软件；HL3 是**开放计量平台**——内核开源可审计、数据格式公开（HDF5 schema）、每个数带不确定度、每份报告可第三方复算。

## 1. 用户画像（Personas）

四个画像按"决策权 × 使用频度"排序。每个画像的"成功信号"直接挂 R1-F2 Gate，避免空泛。

### 1.1 P-A · 实验室 PI（课题组负责人，力学/材料/土木）

| 维度 | 内容 |
|------|------|
| 情境 | 经费有限，多课题共用一套光测设备；论文面临可复现性审查；学生毕业流动导致经验流失 |
| 痛点 | 商业许可绑定单机 + 价格高、评估流程按天计；黑箱结果被审稿人质疑；参数选择依赖某个"会用的学生" |
| 核心诉求 | 学术免费层；UQ 默认输出可写进论文（每个数带 1σ）；工程文件含参数快照 + 图像哈希可复现；公开 Challenge 成绩可引用 |
| 决策角色 | 预算审批者 + 学术口碑传播者（生态起搏点） |
| 关键功能 | 开源内核、`pip install hl3`、噪声底/VSG 研究自动化、Challenge 回归结果包、`.h5` 可作论文补充材料（h5py 直读） |
| 成功信号（Gate） | **GP-1**（噪声底一键化→每点 CI）、**GP-9**（确定性/可复现）、**G2D-3**（MEI 曲线可与已发表结果同图）、**G3D-4**（Stereo Challenge 包络） |

### 1.2 P-B · 试验工程师（工业试验室 / 第三方检测机构）

### 1.3 P-C · FEA 验证工程师（仿真-试验对标 / V&V）

| 维度 | 内容 |
|------|------|
| 情境 | 用 DIC 全场数据验证 FE 模型、辨识材料参数；Abaqus/Ansys/Nastran 用户；受 ASME V&V 类流程约束 |

| 决策角色 | 跨部门影响者（仿真部门预算） |
| 关键功能 | Exodus/VTK/Abaqus inp 导入、DIC↔FE 双向投影、同滤波链对比报告、（SOTA）导入网格上直接全局 FE-DIC |
| 成功信号（Gate） | **GP-4**（FEA 闭环三级）、**GP-1**（每点 CI 支撑 z 检验）、**G3D-6**（应变噪声底声明 VSG） |

### 1.4 P-D · 学生 / 研究生（新用户与教学市场）

| 维度 | 内容 |
|------|------|
| 情境 | 第一次做 DIC；macOS 笔记本或课题组 Linux 集群；导师丢来一组图和一篇 GPG |
| 痛点 | 商业软件评估许可申请周期长；不懂 subset/step/VSG，参数选错而不自知（DIC 最普遍的误用形态，R1-O1 §6.5） |
| 核心诉求 | 15 分钟内从安装到第一张应变云图；软件替他执行良好实践（向导给红黄绿判定与整改建议）；免费、跨平台、有 notebook 教程 |
| 决策角色 | 未来 5 年的工程师/PI——生态的种子用户 |
| 关键功能 | `pip install hl3` + 示例数据、良好实践向导（图案体检→参数推荐→噪声底→VSG 研究→离面评估）、报告自动 GPG 合规 |
| 成功信号（Gate） | TTFR ≤ 15 min（R1-F1 KPI-5，产品级 KPI）、**GP-2**（VSG 自动研究）、**G2D-9**（离面误差预算向导）、**GP-8**（三平台） |

**画像→分级权重**：MVP 优先满足 P-A / P-D（开源+精度+可复现，获取信誉与生态）；v1 补齐 P-B（采集/实时/报告，进入收费市场）；P-C 在 v1 得到"对比"能力、在 SOTA 得到"原生闭环"能力。

## 2. 功能分级总则

| 级别 | 定义 | 发版规则（R1-F2 §2 规范性引用） |
|------|------|--------------------------------|

## 8. 商业模式：open-core 边界与付费模块

### 8.1 两条铁律

1. **计量可审计**：凡是 Gate 判定所依赖的算法与工具（相关器、标定、应变、UQ 计算、基准脚本、schema 读取器）必须在开源层可复现——第三方无需付费即可验证我们的全部精度宣称。这是"开源内核 = 信任资产"叙事（R1-F3 楔子 #5）的产品化约束。
2. **付费 = 工业集成与规模化便利，不是精度**：任何付费模块不得让免费用户的测量结果变差；付费买的是"接入试验机/产线/大规模部署"的工程能力与服务。

### 8.2 开源层（宽松许可；具体许可证由 R2-G1 的 ADR 唯一裁决，本 PRD 只冻结边界）

| 组件 | 内容 |
|------|------|
| `hl3-core` | 局部 ICGN（一阶/二阶）、全局 FE-DIC / ALDIC 内核、标定（Zhang+BA+bootstrap 协方差）、三角化、应变张量族、**UQ 计算内核**（逐点协方差、噪声底、VSG 研究计算） |
| `hl3-python` + CLI | `pip install hl3` 全链 API、批处理 CLI、示例 notebook |
| `hl3-formats` | HDF5/Zarr schema 规范文档 + 参考读取器（Python/MATLAB）+ 导出器（CSV/VTK/Exodus/.mat） |
| `hl3-bench` | 合成散斑生成器、Challenge 回归 harness、benchmark manifest 与复现脚本 |
| `hl3-target` | 标定靶生成器（PDF/SVG + target.json + 打印校验标尺） |
| 社区版 GUI | 基础工作流（AOI/运行/云图/提取器/基础报告）。**形态（开源 vs 免费闭源）随许可证 ADR 一并由 R2-G1 裁决**；本 PRD 要求：免费获取、无许可摩擦、覆盖 MVP 全部 Gate 场景 |

**独立实现纪律**：不拼装 OpenCorr GPU 闭源库；ICGN/CUDA 独立实现（R1-G1 结论，ROUND1_BRIEF 冲突 1）；MPL-2.0 文件级义务评估随 ADR 落地。

### 8.3 付费层（商业许可，按模块订阅/浮动）

| 付费模块 | 内容 | 对标/理由 |
|----------|------|-----------|

| **HL3-Capture Pro** | 厂商私有 SDK 插件（Photron/Phantom/Basler 高级特性）、高速落盘、相位触发/峰谷采样、多机采集编排。GenICam 标准路径保持免费 | 对标 VIC-Snap 深度集成；私有 SDK 有授权成本 |
| **多系统拼接模块** | N 相机位姿图 + 全局 BA + 重叠区逆方差融合（P8.1） | 对标 16 相机多系统（系统级加价方案），HL3 无架构上限 |
| **振动 FFT/ODS 模块** | 全场 FFT/FRF/ODS 振型动画、UNV 导出、相位锁定工作流（P8.2） | 对标 VIC-3D ODS 系统 |
| **IR 融合模块** | IR-可见光互标定、温度场重投影、热-力耦合输出（P8.4） | 对标 VIC-3D IR 系统 |
| **显微/SEM 模块** | 仅在 FTO 书面结论后立项（P8.3） | 对标 VIC Micro/SEM |
| **GUI Pro** | iris 级动画编辑、出版级模板库、批量报告、企业模板管理 | 对标 iris 打磨面 |
