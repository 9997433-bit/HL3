## 1. 审计维度（Audit Dimensions）

13 个维度。每个维度定义：**量化指标（Metric）→ 测量方法（How）→ 证据工件（Evidence）**。Round 2/3 所有"我们更好"的论断必须落到这些指标上，禁止无工件的口头宣称。

### D1 计量精度（Metrology Accuracy）

- **指标**：
  - M1.1 刚体平移偏差：合成/实验平移序列上，位移均值误差（bias）与亚像素周期性偏差（interpolation S-curve）峰峰值，单位 px。
  - M1.2 位移噪声底（noise floor）：静态图像对的空间/时间标准差 σ_u（px），按 GPG §5.4.2 双指标。
  - M1.3 应变准确度：已知均匀应变场（合成 + 拉伸标样）上的应变均值误差与 σ_ε（µε），在**声明的 VSG** 下。
  - M1.4 大行程 3D 误差包络：Stereo Challenge 1.0 协议下 ±20 mm 行程的 3D 坐标误差（µm）。
- **方法**：Challenge 数据集 + 自建合成散斑生成器（含 Balcaen 型 FE 变形渲染），噪声用异方差相机噪声模型；每个指标在多套散斑图案上取平均以分离 PIB（A4）。
- **证据**：`benchmarks/metrology/metrics.json` + 自动生成图（误差-行程曲线、S 曲线）。

### D2 空间分辨率 vs 噪声（含 VSG 尺寸效应）

- **指标**：
  - M2.1 位移空间截止周期：Star1/Star2 图，20% 衰减阈值下的截止周期（px），随 subset 扫描。
  - M2.2 应变空间截止周期：Star3/Star4 图，随 VSG 扫描。
  - M2.3 MEI：按 Challenge 2.0 定义计算，与论文发表的主流软件曲线同图对比。
  - M2.4 VSG 传递函数：自动 VSG 研究输出的"噪声 σ_ε vs 截止周期"帕累托曲线（GPG §5.4.5）。
- **方法**：星图中心行提取 + 多噪声实例平均（分离 PIB 与随机噪声，A4）；每次发版重跑。
- **证据**：`benchmarks/star/` 曲线 + MEI 榜单快照。

### D3 鲁棒性（大应变、不连续、光照）

- **指标**：
  - M3.1 大应变上限：合成/橡胶拉伸序列，增量参考（re-reference）下可跟踪的最大工程应变（%）及累计漂移（N 次换参考后静态回零误差 ≤ 2×σ_u）。
  - M3.2 不连续容忍：含裂纹/孔洞合成场，裂纹两侧 2×subset 范围内有效点覆盖率（%）与假应变污染带宽度（px）；subset 分裂/掩膜相关是否可用。
  - M3.3 光照鲁棒：ZNSSD/ZNCC 下，线性亮度增益 ±30%、偏置 ±20 灰阶、局部高光/阴影序列的失配率（%）与 σ_u 退化倍数。
  - M3.4 失相关恢复：种子丢失后自动重播种成功率；遮挡后重入 ROI 的恢复帧数。
- **方法**：脚本化扰动注入（增益/偏置/渐晕/运动模糊）；裂纹场用解析 Westergaard 位移场渲染。
- **证据**：`benchmarks/robustness/` 报告；每项给出失效边界而非单点结论。

### D4 立体标定质量

- **指标**：
  - M4.1 标定分数：全部标定图的加权重投影残差 RMS（px），并输出**逐图分数**（GPG Rec 支持剔除离群图）。
  - M4.2 极线误差：静态/平移散斑图上的平均与逐点极线误差（px），及其与标定分数之比（A3：应同量级）。
  - M4.3 参数合理性：重建立体角/基线与物理摆放偏差（°）；畸变模型阶次选择的残差图无系统纹理。
  - M4.4 标定稳定性：自举重采样（bootstrap）标定参数置信区间；同步误差自动诊断（单目可标、双目分数劣化 → 报同步告警，GPG §3.2）。
- **方法**：Stereo Challenge 提供的标定图组（14×10-10mm 等靶）+ 自采靶图；与论文公布的 0.018 px 级分数对比（A5）。
- **证据**：标定报告 JSON（内含逐图分数、协方差、靶规格、图像哈希）。

### D5 不确定度量化（UQ）

- **指标**：
  - M5.1 每点位移/应变置信区间输出（噪声传播 + 插值偏差 + 标定不确定度合成）。
  - M5.2 校准性：合成真值上 95% CI 的实证覆盖率 ∈ [90%, 98%]。
  - M5.3 噪声底自动化：一键"静态图 → 空间/时间 σ → QOI 噪声底报告"（GPG §3.3.3.1 / §5.4.2）。
  - M5.4 2D 离面误差预算：给定 Z、ΔZ 估计假应变 ≈ ΔZ/Z（非远心镜头），向导内实时显示（GPG §5.4.3）。
- **方法**：解析传播 + 蒙特卡洛双通道相互验证。
- **证据**：UQ 白皮书 + 覆盖率回归测试。

### D6 用户体验（UX）

- **指标**：完成标准流程（导入→ROI→种子→运行→应变→导出）的操作步数与新手用时；向导覆盖率（GPG 各 Recommendation 中被产品向导承接的比例，见 §3）；崩溃率（fuzz 畸形图像不崩溃）；撤销/重做与工程文件完整性。
- **方法**：脚本化 UI 冒烟 + 任务型可用性走查记录。
- **证据**：UX 走查纪要 + 自动 UI 测试报告。

### D7 自动化

- **指标**：CLI 批处理覆盖全部 GUI 分析能力；Python API（对标 vicpyx）可完成"标定→相关→应变→导出"全链；参数模板/工程模板；自动起点检测成功率；无头（headless）模式。
- **证据**：API 契约测试 + 示例 notebook。

### D8 实时（Real-time）

- **指标**：
  - M8.1 离线吞吐：点/秒（声明硬件、subset、形函数、插值阶次）。
  - M8.2 在线全场：5 MP 图像流的持续帧率与端到端延迟（ms）。
  - M8.3 虚拟引伸计/应变片点测（对标 VIC-Gauge）：更新率（Hz）与延迟；模拟量/触发同步抖动。
- **方法**：固定基准机（CPU 32 核 + 消费级 GPU 各一档）复现；对 A6 的 1M 点/秒仅作"公开宣传对标线"。
- **证据**：性能仪表板（含硬件披露），发版间不允许 >5% 回退。

### D9 FEA 闭环

- **指标**：FE 网格导入（Exodus/VTK/Abaqus inp/STL/OBJ/PLY）；DIC 点云→FE 网格投影误差；DIC–FEA 场对比指标（残差场、直方图、逐节点差）；导出实测边界条件；（SOTA）在导入网格上直接做全局 FE-DIC（呼应 GPG Ed.2 Global DIC 附录，A1）。
- **证据**：端到端示例工程（公开 FE 模型 + Challenge 图像）。

### D10 报告

- **指标**：报告模板自动嵌入 GPG"报告清单"全部元数据（subset、step、VSG、插值、形函数、匹配准则、预/后滤波、标定分数、极线误差、噪声底、图像哈希、软件版本）；出版级图（等值线、变形动画、4K/PDF）；批量模板报告。
- **证据**：样例 PDF/HTML 报告 + 元数据完备性 lint。

### D11 相机生态

- **指标**：GenICam（GigE Vision / USB3 Vision）通用接入；≥2 家厂商 SDK 适配；硬件触发与多相机同步（同步误差 < 1 行曝光时间）；高速相机文件格式（cine 等）导入；标定/散斑辅助采集工具（对标 VIC-Snap）。
- **证据**：硬件在环测试记录（可用低成本双工业相机台架）。

### D12 许可与部署

- **指标**：Linux/Windows/macOS 三平台 CI 构建与基准一致性（数值差 < 1e-6 相对）；许可摩擦（离线激活、浮动许可、无 PC 专属密钥流程——对比 VIC 公开短板）；SBOM 与第三方许可证兼容（OpenCorr MPL-2.0、DICe 许可需复核等）；安装体积与冷启动时间。
- **证据**：SBOM + 许可证矩阵 + 三平台基准差异报告。

### D13 可重复性（Reproducible Science）

- **指标**：确定性模式（同输入同输出，跨线程数不变）；工程文件记录全部参数 + 输入图像哈希 + 内核版本；数据集清单（SHA256 manifest）；基准结果可由第三方从干净克隆一键复现。
- **证据**：`repro/` 一键脚本 + 双机复现差异报告。

## 3. iDICs GPG（Edition 2）→ 产品功能映射

## 4. Challenge 数据集强制回归（Mandatory Regression）

### 4.1 数据集清单（全部公开，idics.org/challenge）

| 套件 | 内容 | 用途 |
|------|------|------|
| 2D-DIC Challenge 1.0（Reu 2018, doi:10.1007/s11340-017-0349-0） | Sample 1–15（平移、拉伸、含噪、星图前身） | 基础精度回归 |
| 2D-DIC Challenge 2.0（Reu 2022, A4） | Star1（无噪位移）、Star2（异方差噪声位移）、Star3（无噪应变 5%）、Star4（噪声应变） | 空间分辨率/MEI/PIB 回归 |
| Stereo-DIC Challenge 1.0（2024, A5） | StereoSample1（实验平移）、2（仿真平移）、3/4（D 试样实验/仿真拉伸）、5（哑区拉伸）、6（远心）；16 mm 与 35 mm 标定组 | 3D 全链回归（标定→重建→应变） |
| 自建合成集 | Balcaen 型 FE 渲染 + 解析场（裂纹、旋转、大应变）+ 噪声/光照扰动 | 补 Challenge 未覆盖的鲁棒性维度 |

### 4.2 CI 规则（强制）

1. **数据完整性**：数据集不入库，用 SHA256 manifest + 下载脚本固定版本；下载页许可条款快照存档（数据"freely available"，但引用须按论文要求标注）。
2. **分层执行**：每 PR 跑冒烟子集（<5 min：Star2 单 subset 档 + StereoSample1 单行程）；每夜跑全量；每发版跑全量 × 多散斑平均。
3. **回归判据**：任何 Gate 指标相对上一发版劣化 >2% → CI 红；MEI/截止周期曲线整体劣化 → 阻断发版。
4. **结果对齐文献**：每次全量跑生成"与已发表曲线同图"的对比图（Challenge 2.0 的 MEI 图、Stereo 1.0 的误差-行程图），作为对外可引用的证据链。
5. **PIB 纪律**：凡精度类指标必须 ≥3 套散斑图案平均后判定，禁止用单一图案调参过拟合（A4）。
6. **禁止项**：不得以任何方式将 VIC 软件本体跑进 CI（法律边界）；与商业软件的对比一律引用**已发表**数字（Stereo Challenge 1.0 论文中五款商业软件结果是目前最好的合法代理，见 §6-R2）。

## 6. 残余风险：若始终无法在 Windows 上合法评估 VIC

前提：本环境（Linux Cloud Agent）无法完成 VIC 官方 30 天评估的合法闭环（见 LEGAL.md）。即使一切公开对标做满，仍存在以下不可消除或部分可缓解的风险：

| # | 风险 | 影响 | 缓解（合法） | 残余等级 |
|---|------|------|--------------|----------|
| R1 | **UI/工作流基准缺失**：VIC 实际操作流畅度、缺省参数质量、报告观感只能从公开视频/网研会推断 | 可能在"好用"维度错判竞争线，v1 交互低于市场预期 | 公开演示视频/网研会走查；若用户持合法许可，后续在其 Windows 工作站做 UI 走查（LEGAL.md 已预留）；beta 用户访谈 | 中 |
