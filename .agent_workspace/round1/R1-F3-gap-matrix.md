## 4. Istra4D / DaVis 补充观察（不列主矩阵，作趋势佐证）

- **Istra4D（Dantec，S11）**：V4.11 公开更新 = 编码标记点自动识别、自动最优 subset 尺寸、实时相关模块并入标准包、Python 应用脚本、峰谷/频闪触发。**信号**：实时相关与 Python 脚本正在从"高端选配"变成"标配"，HL3 必须默认内置。
- **DaVis（LaVision，S12）**：强在采集平台一体化（软件同时管相机/照明/DCU 时序）与流固耦合、多相机、显微场景。**信号**：采集-分析一体平台是行业共识，验证 HL3 "共享采集抽象层" 决策正确。
- 两者与 VIC 一样均为 Windows 桌面 + 硬件捆绑销售——**跨平台与许可自助化在整个商业阵营中无人做**，楔子 #1/#2 的窗口是真实的。
