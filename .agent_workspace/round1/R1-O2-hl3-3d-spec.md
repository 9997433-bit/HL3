# R1-O2 · HL3-3D 立体数字图像相关（Stereo-DIC）核心规格与算法落地

- **子代理**：R1-O2（opus-fast），Round 1，4/3/3 编制
- **对标对象**：Correlated Solutions VIC-3D 11.x（仅依据公开产品页、公开知识库文章、公开发布说明）
- **法律基线**：遵循 `.agent_workspace/LEGAL.md`。本文件不含任何来自 VIC 二进制、专有手册或逆向工程的内容。所有算法均来自公开发表文献与开源实现（各自许可证下）。
- **配套文件**：`R1-O1-hl3-2d-spec.md`（2D 内核）、`R1-O3-shared-kernel.md`（共享数据模型/API）。本文件只规定 **立体特有** 部分，2D 相关器（ZNCC/ZNSSD、FFT-CC、ICGN、可靠性引导）视为共享内核既有能力，此处仅描述立体侧的调用契约与差异。

## 0. 摘要：一句话定位

> HL3-3D 不是"再写一个立体相关器"，而是把 **标定 → 匹配 → 三角化 → 位移 → 应变 → 多系统拼接 → FEA 验证** 整条测量链做成 **带不确定度传播、可复现、GPU 加速、跨平台** 的计量级产品；在 iDICs Stereo-DIC Challenge 1.0 这一 **公开可复现的公平擂台** 上，以公开数字证明优于当前五家商业码（含 VIC）的公开成绩。

### 1.2 iDICs Stereo-DIC Challenge 1.0 的公开实测成绩（**真正的靶子**）

来源：Reu 等，*Stereo-DIC Challenge 1.0 – Rigid Body Motion of a Complex Shape*, Experimental Mechanics (2024), DOI 10.1007/s11340-024-01077-7；参与方公开列为 Dantec、LaVision、DICe、MatchID、Correlated Solutions（论文中匿名为 Group 1–5）。图像集与对比脚本在 https://idics.org/challenge/ 免费公开。

| 指标 | 五家商业码公开成绩 | **HL3-3D 验收目标（M2 硬门槛）** |
|---|---|---|
| 绝对位移最大误差（±20 mm 面内 + ±20 mm 离面行程） | < ±80 µm，即 0.2% 满量程 | **≤ ±40 µm（0.1% FS）** |
| 典型位移误差 | ±15 µm ≈ ±0.25 像素（16.35 px/mm 标尺） | **≤ ±8 µm ≈ ±0.13 像素** |
| 平坦区形貌误差 vs 激光扫描 | < 33 µm | **≤ 25 µm** |
| 三角棱斜面区形貌误差 | 50–100 µm | **≤ 50 µm，且左右斜面误差不对称度 ≤ 1.5×** |
| 16 mm 广角（畸变约为 35 mm 的 10×）相对 35 mm 的误差劣化 | "modest increase" | **全场标准差劣化 ≤ 20%** |
| 三角化系统性条纹（moiré） | Group 2 出现 | **残差场功率谱无显著周期峰（检验见 §14.4）** |
| 边缘/间断覆盖率 | 各组均在三角尖、圆柱顶、台阶边丢点 | **在同等质量门限下，有效点数 ≥ 公开最佳组 +10%** |
| 立体标定 RMS（Sample 3 报道值） | 0.018 px | **≤ 0.015 px，且给出 bootstrap 95% 置信区间** |
| 不确定度输出 | 论文明确指出各家主要靠相关系数 + 重投影阈值做质量门限 | **每点 3×3 位置协方差 + 应变协方差，随结果一并落盘** |

> 论文的两个关键教训被直接写进 HL3-3D 设计：
> 1. **"预处理阶段的大部分误差只是坐标系不对齐"** —— 所以坐标系对齐必须是内建的一等公民向导，而不是用户自己后处理（§7.3、§8）。
> 2. **PIB（插值/图案诱导偏差）是仅次于未校正镜头畸变的第二大误差源** —— 所以 HL3-3D 必须内建 PIB 估计与补偿（§6.5）。

**关键架构决策（与多数实现不同，逐条给理由）**

| 决策 | 内容 | 理由 |
|---|---|---|
| D1 | **不做立体校正（rectification）重采样后再匹配**；在原始畸变图像上匹配，畸变模型进入代价函数与三角化 | 校正重采样引入一次额外插值，直接放大 PIB。Challenge 已证明 PIB 是第二大误差源 |
| D2 | **形貌（S2/S3）与变形（S4/S5）解耦但共享 Hessian** | 逆合成 ICGN 的参考子集 Hessian 只算一次，立体与时间两条匹配都能复用，省 ~35% 算力 |
| D3 | **四路闭环强制一致性检验**（左参→右参→右变→左变→左参） | 提供一个不依赖真值的自洽误差指标，可在无标准件现场做质量判定；VIC 公开资料未见等价指标 |
| D4 | **不确定度是数据结构的一部分，不是插件** | 每个 POI 携带 3×3 位置协方差与应变协方差，使 FEA 对比可做统计判定而非"看图说话" |
| D5 | **GPU 优先但 CPU 逐位可复现**（容差 ≤ 1e-4 px） | 计量溯源要求结果可在无 GPU 的审计机器上复现 |

## 3. S0 采集与同步

### 3.1 双相机采集契约

- 抽象层：GenICam / GenTL（Harvester 风格）为主路径，厂商 SDK（Basler pylon、FLIR Spinnaker、Photron、Vision Research Phantom、IDS peak）为适配插件。**采集抽象与 2D 共用**（对标 VIC-Snap 的角色，但跨平台）。
- **硬件同步是默认，不是选项**：主从触发或外部函数发生器共触发；软件触发仅在明示降级模式下允许，并在数据元信息里打 `sync_mode=software` 与 `sync_jitter_estimate` 标记。
- 每帧记录：相机时间戳（设备时钟）、主机接收时间戳、触发序号、曝光实测、增益、温度（若可读）。**同步审计器**在采集后给出跨相机时间戳偏差直方图；超过 0.1×曝光时间即告警。
- 卷帘快门相机：记录行曝光时间，提供 rolling-shutter 几何补偿开关（把行索引作为时间变量进入三角化）。VIC 公开资料未强调此项，是可攻击点。

### 3.2 模拟量与载荷同步

- 支持 NI-DAQmx / LabJack / 通用 CSV+时间戳导入 / 串口。
- 载荷、位移、引伸计、热电偶与图像序号对齐，写入同一 HDF5 时间轴。Challenge 的 Sample 3/5 就自带 MTS 载荷与 LVDT 数据，是天然的联调用例。

## 4. S1 标定子系统（HL3-3D 最重要的差异化）

Challenge 的结论是：五家码算法差别不大，**差别主要来自标定**。因此标定是本项目投入最重的模块。

### 4.1 相机模型

分层可选，避免"一刀切"：

| 层 | 模型 | 参数 | 适用 |
|---|---|---|---|
| L0 | 针孔 | fx, fy, cx, cy, skew（默认锁 0） | 全部 |
| L1 | Brown–Conrady | k1,k2,k3 + p1,p2 | 常规机器视觉镜头 |
| L2 | 有理畸变 | + k4,k5,k6 | 广角（如 Challenge 的 16 mm Tamron） |
| L3 | 薄棱镜 + 倾斜传感器 | s1..s4, τx, τy | 装配偏心、Scheimpflug |
| L4 | 鱼眼（等距/等立体角） | Kannala–Brandt | 超广角 |
| L5 | 远心 / 正交投影 | 放大率 + 一阶畸变 | 远心镜头（Challenge Sample 6） |
| L6 | **非参数畸变场**（B 样条控制网格叠加在 L1–L3 之上） | 控制点位移场 | 立体显微镜、SEM、复杂光路 —— **见 §10.4 专利检索标记** |

**模型选择助手（差异化）**：对同一组标定图，自动拟合 L1/L2/L3，用 **留一交叉验证 + AIC/BIC** 选阶，输出"该镜头推荐 L2，L3 过拟合（CV RMS 上升 0.004 px）"这样的可读结论。理由：Challenge 明确指出 16 mm 与 35 mm 镜头畸变差 10×，模型阶数选错会直接吃掉精度预算。

### 4.2 标定流程

1. **靶点检测**
   - 棋盘：亚像素鞍点（Geiger/Duda 风格 + 迭代精化）。
   - ChArUco：ArUco 定位 + 鞍点插值，**允许部分遮挡与出画**，这是把靶推到画面四角以约束畸变的关键（OpenCV 官方与 calib.io 都明确推荐 ChArUco 优于纯棋盘）。
   - 圆点阵：椭圆拟合 + **投影中心偏移修正**（圆心在透视投影下不等于椭圆中心；短焦 + 大圆时偏差显著）。OpenCV 默认只做质心，不做该修正——这是我们相对 OpenCV 基线的直接精度增益。
   - 编码点阵：使用 **自有编码方案**（ArUco/AprilTag 家族或自定义汉明码），**不复制任何厂商靶标的编码布局**（如 CS 的"3 个特殊点"识别布局属其产品设计，避免直接照搬）。

2. **单相机内参**：Zhang 平面标定法（Zhang, IEEE TPAMI 2000）求闭式初值 → LM 非线性精化，最小化重投影误差。

3. **立体外参**：由各视图的靶位姿求 R, t 初值（Procrustes / 位姿差的旋转平均），再进入联合优化。

4. **联合束调整（Bundle Adjustment）**：把两（或多）相机内参、畸变、相对外参、每帧靶位姿、（可选）靶点自身的平面外偏差一起优化。
   - 代价：加权重投影残差，权重用检测协方差（鞍点/椭圆拟合本身的不确定度），Huber 鲁棒核。
   - 求解：稀疏 Schur 补 + 稀疏 Cholesky（Ceres 风格自研或依赖 Ceres/g2o，许可证 BSD/兼容）。
   - **靶标非理想性建模（差异化）**：允许把靶点的实际坐标作为弱约束自由变量（"self-calibrating target"），吸收打印/激光刻蚀误差与靶板轻微翘曲。自印靶因此可逼近商用靶精度 —— 这直接打击 VIC "必须买我家 NIST 溯源靶" 的硬件绑定。

5. **不确定度**：**Bootstrap Monte Carlo**（Challenge 参考文献链条中 BIPM GUM 风格的做法）对标定帧重采样，得到内外参完整协方差矩阵 Σ_cal；后续所有 3D 点协方差都由它传播（§6.6）。VIC 公开资料只报一个"calibration score"标量，我们报完整协方差 —— 这是可量化的产品级超越。

### 4.3 极线误差度量（明确定义，全部落盘）

给定基础矩阵 F（由标定的 K, R, t 与畸变模型在**去畸变归一化坐标**下解析得到，不用八点法估计）：

| 指标 | 定义 | 用途 |
|---|---|---|
| 单向极线距离 | `d(x', l') = |x'ᵀ F x| / sqrt((Fx)₁² + (Fx)₂²)` | 快速门限 |
| 对称极线距离 | `d_sym = ½[d(x',Fx) + d(x, Fᵀx')]` | 对称、无偏 |
| **Sampson 距离** | `d_S² = (x'ᵀFx)² / [(Fx)₁²+(Fx)₂²+(Fᵀx')₁²+(Fᵀx')₂²]` | 一阶几何距离近似，作为默认 POI 级质量场 |
| 三角化后重投影残差 | 三角化得 X，重投影回两视图取 L2 范数 | 最终质量门限，含畸变模型误差 |
| 视差残差 | 实测视差 − 由平滑视差面预测值 | 检测误匹配跳变 |
| **四路闭环残差**（§6.4） | 左参→右参→右变→左变→回左参 的像素回环误差 | 唯一不依赖真值的自洽指标 |

标定阶段还额外报告：
- 每帧、每点的重投影残差场（不是只有一个 RMS 数字）；
- 残差的**空间结构检验**：若残差在图像上呈现明显径向或象限结构 → 提示畸变模型欠拟合（自动建议升阶）；
- 标定体内外的**外推风险图**：测量体素落在标定体外时给红色警示（Challenge 中最大误差常出现在 FOV 角落与基线上，正是外推区）。

**体积覆盖引导（Volume Coverage Guidance，强差异化）**

Challenge Sample 1 用了 **77 张**标定图"spread throughout the calibration volume and with a wide variety of motions"，Sample 3 用了 **65 对**。这句"spread"目前在所有软件里靠人肉经验。HL3 把它量化：

- 把标定体离散为 6 维格子：`(u, v)` 靶中心的图像位置（4×4 网格）× `z` 深度（5 档，覆盖预期测量体 ±20%）× `pitch/yaw` 倾角（−45°..+45°，5 档）× `roll`（4 档）。
- 实时热图：绿=已覆盖、黄=欠采样、红=空白；**下一最佳视角（next-best-view）提示**——直接在实时画面上画出建议的靶位姿轮廓，用户对上去即可。
- 覆盖判据不只是"格子填满"，还看 **Fisher 信息矩阵的条件数**：若 k3 与 cx 的相关系数 > 0.95，提示"焦距/主点/畸变高度耦合，请增加大倾角与画面边缘帧"。
- 达标条件：格子覆盖率 ≥ 90%，画面四角各至少 3 帧有靶点，条件数 ≤ 阈值。达标前 UI 明确显示"标定尚不可信"。

**拒帧（Rejected Frames）管理**

每一帧一行，可排序可筛选，给出**结构化拒绝理由**而不是一个笼统的分数：

| 列 | 含义 |
|---|---|
| 检出点数 / 应有点数 | 检测完整性 |
| 单帧重投影 RMS / P95 | 该帧质量 |
| 离群点数（> 3σ） | 局部误检 |
| 清晰度（Laplacian 方差 / 频谱高频能量） | 离焦、运动模糊 |
| 曝光健康（饱和像素比、直方图占用） | 过曝/欠曝 |
| 靶面倾角 | 过小 → 对 f 无约束；过大 → 检测退化 |
| 覆盖贡献度 | 该帧填补了哪些空格子（删掉会不会打穿覆盖） |
| 自动建议 | `KEEP` / `REVIEW` / `REJECT:<reason>` |

- **一键拒绝 + 即时重标定 diff**：显示"拒绝该 7 帧后：RMS 0.021→0.016 px，f 变化 0.03%，k1 变化 2.1%，3D 点协方差平均缩小 12%"。让用户看到取舍后果，而不是盲操作。
- **拒帧不是删除**：所有拒绝帧保留在工程内并记录理由与操作者，标定报告可完整复现。这是计量审计（ISO 17025 / ASME V&V）需要的。
- 自动"留一影响分析"：找出对参数影响异常大的杠杆帧（高 leverage），提示复核。

## 5. S2 立体匹配（参考帧）

### 5.1 分层策略

```
Stage A  全局初值：SIFT / AKAZE 特征 + RANSAC(F 已知 → 只做外点剔除)
         → 稀疏对应 → 拟合视差面（双线性/薄板样条）
Stage B  极线约束一维搜索：沿极线以 ≤ ICGN 收敛半径（约 3–5 px）为步长
         用 ICGN2D1（宽松收敛、少迭代）粗扫，取 ZNCC 最高者
Stage C  精匹配：ICGN2D2（二阶形函数）在原图（含畸变模型）上收敛
Stage D  质量门限：ZNCC、Sampson 距离、重投影残差、四路闭环残差
```

这条路线与 OpenCorr 的 `EpipolarSearch` + `FeatureAffine` + `ICGN2D2` 组合同构（Jiang, Opt Lasers Eng 2023, 165:107566；Lin 等, Opt Lasers Eng 2021, 149:106812 路径无关立体 DIC）。**我们的增量**：

1. **二阶形函数是立体匹配的默认，不是选项**。立体两视图之间存在真实的透视畸变（Challenge 明确观察到"左斜面因右相机透视更强而误差更大"），一阶形函数在斜面上系统性欠匹配（Schreier & Sutton 2002 的欠匹配偏差）。默认二阶 + 在平坦区自动降阶以省算力。
2. **自适应子集**：在高梯度/斜面区自动缩小、在低纹理区自动放大，形状可各向异性（沿极线方向与垂直方向不同半径）。参考 OpenCorr 的 self-adaptive subset 思路，独立实现。
3. **边界形函数（差异化，直击 Challenge 痛点）**：Challenge 结论明确写道"所有码在三角尖、圆柱顶、台阶边都丢点，subset 方法无法测到间断处"。HL3 引入：
   - **掩膜感知子集**：子集跨越已知间断线时，只用间断一侧的像素，权重图归一化（借鉴 Ncorr 的不规则 ROI 处理并推广到 3D 边界）。
   - **间断自动检测**：由参考帧形貌的曲率/深度不连续 + 匹配残差突变共同判定，生成候选间断线供用户确认。
   - 目标：同等质量门限下有效点数 ≥ 公开最佳组 +10%。
4. **深度学习只做种子**：Stereo-DICNet 一类网络（如 LianpoWang/Stereo-DICNet2）用于大视差/弱纹理/遮挡区的初值，**绝不替代 ICGN 输出计量结果**；所有 DL 种子必须经 ICGN 收敛并通过同一质量门限，否则标记为 `seed_only` 不参与最终场。

### 5.2 时间匹配（S4）

- 各视图独立做 2D 时间匹配（复用 2D 内核，见 R1-O1）。
- **增量 vs 累积**双模式：增量（帧对帧）抗大变形，累积（对参考帧）无漂移。默认混合：累积为主，累积失败点自动回退到增量并做链式合成，链长与漂移估计写入元信息。
- 大刚体位移场景（VIC 宣称"不受大刚体位移影响"）：用上一帧结果 + 全局仿射预测做初值传播；配合 §5.1 Stage A 的特征法在跳变时重锚。

## 6. S3/S5 三角化与 3D 位置

### 6.1 三角化算法阶梯

| 方法 | 用途 |
|---|---|
| 中点法（两射线最近公共点） | 初值，快 |
| 线性 DLT | 初值，快 |
| **Hartley–Sturm 最优三角化 / 迭代 Sampson 修正** | 默认，L2 意义最优 |
| **非线性重投影最小化（GN/LM，带完整畸变模型）** | 高精度模式与多视图（>2 视图）情形，默认在 M2 后成为标准路径 |

多视图（同一点被 ≥3 台相机看到，多系统重叠区）直接走非线性多视图三角化，按各视图观测协方差加权。

### 6.2 为什么不做 rectification

立体校正会把图像重采样到共面行对齐坐标系。重采样 = 一次额外插值 = 一次额外 PIB 注入，且校正映射本身在大畸变（16 mm 广角）下高度非均匀，误差分布不均。HL3 全程在原始像素栅格上工作，畸变仅在**几何模型**中出现，从不在**像素数据**上出现。代价是极线是曲线（畸变下的极曲线），需要数值求解极曲线采样点——已在 §5.1 Stage B 的一维搜索中处理，额外开销 < 5%。

### 6.3 极曲线采样

在畸变模型下，视图 2 中对应视图 1 某点的极线不是直线。做法：
1. 在归一化去畸变坐标下得到直线极线；
2. 沿该直线取参数 t 采样；
3. 对每个采样点施加**正向畸变**映射回视图 2 的像素坐标，得到极曲线上的采样序列；
4. 搜索在该序列上进行。避免了"对整幅图去畸变"。

### 6.4 四路闭环一致性检验（差异化指标）

对每个 POI 建立回环：

```
p_L,ref  --(立体匹配)-->  p_R,ref
p_R,ref  --(时间匹配)-->  p_R,def
p_R,def  --(立体匹配)-->  p_L,def
p_L,def  --(时间匹配,逆)--> p̂_L,ref
```

回环残差 `ε_loop = ||p̂_L,ref − p_L,ref||`。

- 这是一个**不需要任何真值、不需要标准件**的自洽误差估计，现场即可用。
- 理论上四条匹配误差近似独立，`ε_loop ≈ 2·σ_match`，可反推单次匹配噪声底。
- 用途：(a) 质量门限；(b) 现场散斑质量与光照的即时体检；(c) 与实验室标定不确定度交叉验证。
- 公开资料中未见 VIC-3D 有等价的用户可见指标。

### 6.5 PIB（插值/图案诱导偏差）估计与补偿

Challenge 结论："PIB error source is a limiting factor in the shape reconstruction and the error magnitude, second only to the uncorrected lens distortions at the edges of the FOV."

HL3 的应对（分三层，可独立开关，全部可审计）：

1. **高阶插值**：默认双五次 B 样条（预滤波系数缓存复用，GPU 上用纹理 + 手写系数），而非双三次多项式。B 样条预滤波显著降低插值偏差幅值。
2. **PIB 估计器**：对参考图做已知亚像素平移（0.0→1.0 步进 0.05）的数值实验，统计恢复误差随亚像素相位的周期性曲线，得到该图案 + 该插值核的 PIB 幅值 A_PIB 与相位。这是一次性的、纯软件的、可在任意用户数据上跑的自诊断。
3. **补偿**：
   - 主路径：把估得的 PIB 相位曲线作为反查表在亚像素位置上做去偏（sinusoidal 一阶 + 二阶谐波模型）；
   - 备选路径：对图像做匹配的低通预平滑（σ 由 A_PIB 自动定），以偏差换噪声，向用户显示这一权衡曲线。
4. **验收**：在合成散斑上（真值精确已知）扫描亚像素相位，要求补偿后 PIB 峰峰值 ≤ 0.005 px（未补偿典型 0.01–0.05 px 量级）。

### 6.6 不确定度传播（每点 3×3 协方差）

```
Σ_X = J_g · blkdiag(Σ_match_L, Σ_match_R, Σ_cal) · J_gᵀ
```

- `Σ_match`：由 ICGN 的 Hessian 逆 × 残差方差得到（`σ² (HᵀH)⁻¹` 的位移分量），即相关本身给出的匹配协方差。
- `Σ_cal`：来自 §4.2 的 bootstrap 标定协方差。
- `J_g`：三角化函数对（p_L, p_R, 标定参数）的雅可比，解析求导。
- 输出：每个 POI 的 3×3 位置协方差 → 位移协方差 → 经 §7 的应变算子传播为应变协方差。
- 这条链是 FEA 统计判定（§12.4）和多系统逆方差融合（§9.3）的前提，**没有它，"超过 VIC" 只是口号**。

### 6.7 三角化 moiré 的防治

Challenge 记录了 Group 2 出现 moiré 状条纹（三角化系统误差）。成因通常是：POI 栅格与像素栅格的固定相位关系 + 亚像素偏差 + 线性三角化的一阶近似联合产生的拍频。防治：
- 用非线性三角化（§6.1）而非线性 DLT；
- PIB 补偿（§6.5）消除亚像素相位依赖；
- POI 栅格可选**抖动（jittered）布点**，打破与像素栅格的固定相位；
- 验收检验：残差场做 2D FFT，检查是否存在显著周期峰（§14.4）。

## 7. S6 3D 位移与坐标系

### 7.1 位移定义

`U, V, W = X_def − X_ref`，在**世界坐标系**下（不是相机坐标系）。同时提供：
- `|A| = sqrt(U²+V²+W²)` 位移幅值（Challenge 正是用这个量规避坐标系不对齐的影响）；
- 沿用户定义方向的投影分量；
- 法向/切向分解（相对参考面拟合的局部法向）。

### 7.2 坐标系定义方式

1. 相机 1 光心系（默认原始）
2. 标定靶系（第一帧靶位姿）
3. **三点/平面拟合系**：用户在形貌上点三点或框选平面 → 原点 + 法向 + 面内轴
4. 基准点（fiducial）系：已知实际坐标的标记点最小二乘拟合
5. 主轴系：对 ROI 点云做 PCA
6. 外部导入：从 FE 模型继承坐标系（§12.2）

### 7.3 坐标系对齐向导（直击 Challenge 教训）

Challenge 明确写："Most of the errors measured in the preliminary analysis were simply coordinate system misalignment."

HL3 内建 **对齐诊断器**：
- 当存在外部参考（位移台、编码器、LVDT、FE 模型）时，自动估计"DIC 世界系 → 参考系"的最优刚体变换（含小角度旋转），并**报告该旋转角**。
- 若估得旋转角 > 0.1°，明确提示"存在坐标系不对齐，建议对齐后再比较分量；当前分量误差中有 X µm 属于对齐残差而非测量误差"。
- 提供"分量误差 vs 幅值误差"并列显示，让用户一眼看出误差是不是对齐造成的。
- 这个功能在 Challenge 的复现脚本里是靠人工 MATLAB 处理的；把它产品化即是可见的用户价值。

## 8. S7/S8 表面应变与 3D 刚体运动去除

### 8.1 表面应变张量：三条并行路径

| 路径 | 原理 | 适用 |
|---|---|---|
| **P1 曲面 VSG（默认）** | 在每个 POI 的 kd-tree 邻域内（strain window 直径 = VSG 尺寸），先拟合局部切平面，把邻域 3D 位移投影到该切平面的局部 2D 坐标，做加权最小二乘多项式拟合（一阶/二阶）得位移梯度 → F → E | 通用、与 DICe 的 VSG 后处理同族（DICe 文档明确：立体分析用 MODEL_DISPLACEMENT，距离在拟合平面上度量），便于和现有生态对比 |
| **P2 三角单元 / Cosserat 点单元** | 在点云上建三角网格，用单元顶点位置矢量直接算 F，再得 C、B、E（Green-Lagrange）、e（Euler-Almansi） | MultiDIC / DuoDIC 采用的方法（Solav 等, IEEE Access 2018；DuoDIC, JOSS 2022）。平面三角单元有 λ₃ = 1、E₃ = 0 的天然约束，适合大变形与生物力学 |
| **P3 参数曲面（NURBS/薄板样条）全局拟合** | 对位移场做带正则的全局曲面拟合，解析求导 | 光滑大曲率试样、需要高阶导数（曲率、应变梯度）时 |

三条路径**在同一 UI 里可切换并叠加对比**，差异图直接可视化。VIC 公开资料只暴露一种应变滤波窗口，这里给的是方法论透明度。

### 8.2 应变量输出

- Green–Lagrange `E = ½(FᵀF − I)`
- Euler–Almansi `e = ½(I − B⁻¹)`，`B = FFᵀ`
- 工程应变、对数（Hencky）应变
- 主应变 E₁, E₂ 与主方向（在切平面内）
- 最大剪应变、等效（von Mises）应变、面积变化率
- 曲面几何量：第一/第二基本形式、平均曲率、高斯曲率（用于分离"弯曲导致的表面应变"与"膜应变"）—— **膜/弯分解是 VIC 公开菜单里没有强调的，对薄壳与复合材料客户是实打实的增值**
- 厚度方向估计：给定泊松比或体积不可压假设，反推厚度应变（明确标注为"推断量"）

### 8.3 VSG 尺寸效应与不确定度

- 内建 **VSG 扫描工具**：对同一数据用 VSG = 5, 9, 15, 21, 31 … 点重算，画出"峰值应变 vs VSG 尺寸"与"噪声底 vs VSG 尺寸"两条曲线，交叉点即推荐工作点。iDICs Good Practices Guide 要求报告 VSG，我们让它自动化并写进报告。
- 应变协方差：由位移协方差（§6.6）经最小二乘拟合算子线性传播，得每点应变的 2×2（切平面内）协方差。
- 报告"应变分辨率"这一数字时，必须同时给出 VSG 与空间分辨率 —— 拒绝像营销页那样只给"10–50 µε"而不给条件。

### 8.4 3D 刚体运动去除

**算法**：加权 Umeyama / Kabsch 闭式解（Umeyama, IEEE TPAMI 1991）求 `min Σ wᵢ ||R Xᵢ + t − Yᵢ||²`，SVD 求 R（强制 det(R)=+1）。

**HL3 的四点强化**：

1. **逆方差加权**：`wᵢ = 1/tr(Σ_Xᵢ)`（或完整 GLS 形式用 Σ⁻¹ 加权），高不确定度点自动降权。
2. **鲁棒化**：RANSAC 选内点 + Huber/Tukey IRLS 精化，避免局部变形区污染刚体估计。
3. **参考域可选**：
   - 全场最佳拟合（默认）
   - 用户框选的"应保持刚性"区域（如夹具、非变形段、Challenge Sample 5 的 dummy 区）
   - 附加刚体基准块（贴在夹具上的独立散斑块）—— 这条能把**相机系统自身的漂移**从试样运动中分离出来。Challenge 观察到"the difference between the DIC systems is less than that for the Aerotech, indicating that some rigid-body-motion of the camera systems may be occurring"，正是这个问题。
4. **输出的是诊断，不只是结果**：给出 R(t)、t(t) 时间序列、旋转角、平移量、去除后残差场的 RMS 与空间结构。若残差场有系统性结构（非白噪声），提示"该区域并非纯刚体，或存在标定/畸变残余"。

**顺序注意**：3D 刚体运动去除**不改变应变**（应变对刚体运动不变），它只影响位移显示与形貌配准。UI 必须明示这一点，避免用户误以为"去刚体能降应变噪声"。真正降应变噪声的是 VSG（§8.3）。

## 9. S9 多相机 / 多系统路径（≤16 相机，可扩展至更多）

### 9.1 拓扑模型

- 基本单元是 **stereo system**（2 相机），16 相机 = 8 个系统；也支持 N 目系统（3+ 相机共视，走多视图三角化，§6.1）。
- 系统间关系存为 **位姿图（pose graph）**：节点 = 系统坐标系，边 = 估计出的 SE(3) 变换 + 6×6 信息矩阵。
- 支持"系统组"分层（如：4 个系统绕圆柱一圈为一组，另 2 个系统看端面为另一组）。

### 9.2 系统间配准方法（三选一或混用）

| 方法 | 做法 | 适用 | 精度来源 |
|---|---|---|---|
| **M-A 刚性散斑靶多姿态**（对标 VIC 主推法） | 一块刚性散斑靶（平面/双面/多面体/试样本身），做 ≥15 组任意平移+倾斜（VIC 公开建议 ≥10，我们提高门槛并给覆盖度指标）；每个系统各自 DIC 出靶面的 3D 点云与位姿序列；对同一时刻两系统的位姿做 Procrustes / hand-eye 求解 T_ij | 重叠或非重叠均可 | 散斑点数多 → 统计精度高（VIC 公开宣称双面靶比 marker 法约 10× 提升，机理正是点数） |
| **M-B 基准点（fiducial）** | 已知实际坐标的圆形/象限标记，每系统至少 3 点可见 | 有标定件、需绝对坐标 | 点少，精度受限；作为快速法与交叉校验 |
| **M-C 重叠区形貌 ICP** | 两系统重叠视场的点云做点到面 ICP（锁定尺度） | 有充分重叠且形貌有特征 | 无需额外靶，但平面/柱面区域退化 |

**我们的增量**：
1. **三法融合 + 全局位姿图优化**：把 M-A/M-B/M-C 产生的所有相对约束一起丢进位姿图，做全局最小二乘（Levenberg-Marquardt on SE(3) manifold），而不是像公开工作流那样"逐个把 sys_k 变换到 sys_1"。链式变换会累积误差，图优化不会。
2. **闭环一致性检验**：对任意回路（如 T₁₂·T₂₃·T₃₁），报告偏离单位阵的残差（旋转角 + 平移量）。这是多系统标定唯一的自检指标，且**必须显式呈现给用户**。目标：8 系统绕柱一周，闭环平移残差 ≤ 50 µm、旋转残差 ≤ 0.02°。
3. **全局束调整（可选高精度模式）**：把所有系统的内参、畸变、系统内外参、系统间外参、靶点 3D 坐标一次性联合优化。计算量大但一次搞定，消除"先单系统标定、再系统间配准"的两阶段误差累积。
4. **非重叠拼接的可信度标注**：非重叠拼接的精度完全由配准靶的姿态覆盖决定，且**无法在测量数据上自检**（没有重叠区可比）。HL3 强制在这类结果上打水印式标注：`registration_verifiable=false`，并给出由靶配准协方差外推的位置不确定度包络。诚实标注不确定度本身就是相对营销话术的竞争优势。

### 9.3 重叠区数据融合

- **逆方差加权融合**：重叠区同一物理位置有多个系统的观测，按 `Σ⁻¹` 加权合并，融合后协方差 `(ΣᵢΣᵢ⁻¹)⁻¹`。比"取平均"或"取一个丢一个"都好。
- **系统间偏差（bias）检测**：融合前先检查两系统在重叠区的差值场。若差值有系统性偏移或倾斜 → 配准未收敛或某系统标定有问题，报警而不是默默平均掉。这个偏差场是极佳的整机健康指标。
- **网格合并**：重叠区做 Delaunay 缝合（MultiDIC 的做法是在网格边界顶点间做局部 Delaunay 三角化，最大化最小角），生成连续单一表面网格，供应变计算与 FEA 对比使用。

### 9.4 规模与性能

- 16 相机 @ 5 MP @ 30 fps ≈ 2.4 GB/s 原始数据。设计：分布式采集（多机 + PTP 时间同步）或单机多 10GigE/CoaXPress 卡 + 直写 NVMe RAID。
- 分析侧：每个立体系统的相关计算天然并行，多 GPU 按系统分片；融合与位姿图优化在 CPU 侧（问题规模小）。
- **VIC 公开的是"单 PC 最多 16 相机"**。HL3 不设 16 的硬上限：架构上系统数只受 IO 与位姿图规模限制，宣传口径可为"无架构上限，已验证 N 系统"（N 由实测填写，不吹）。

## 11. 实时能力与性能预算

### 11.1 三级实时模型

| 级别 | 内容 | 点数 | 延迟目标 | 对标 |
|---|---|---|---|---|
| **L0 · 点测量（Gauge）** | 虚拟引伸计、虚拟应变片、少量 3D 点、位移/应变标量输出，可推送到试验机闭环控制 | ≤ 200 个 3D 点 | **端到端 ≤ 2 ms**，抖动 P99 ≤ 0.5 ms；控制输出走独立实时线程（Linux `SCHED_FIFO` + `isolcpus`，Windows 走 MMCSS） | VIC-Gauge（宣称可闭环控制） |
| **L1 · 稀疏全场实时** | 全场但降采样的 POI 子集（等间隔或自适应加密于高梯度区），实时形貌 + U/V/W + 粗应变 | 1×10³ ~ 5×10⁴ 3D 点 | **≥ 60 Hz**（相机能给多少给多少，上限打到 IO） | VIC-3D 全场实时模块 |
| **L2 · 全密度离线/近线** | 全部 POI，二阶形函数，PIB 补偿，完整不确定度 | 10⁵ ~ 10⁷ 3D 点 | 吞吐优先 | VIC-3D 常规分析 |

L0/L1 与 L2 用**同一个内核、同一套参数**，只是 POI 密度与形函数阶数不同。**关键产品承诺：实时预览的结果与最终离线结果在相同参数下逐位一致**（不像"实时用简化算法、离线用另一套"那样出现前后不一致）。

### 11.2 吞吐目标与预算推导

**一个 3D POI 的成本拆解**（子集 31×31 = 961 像素，二阶形函数 12 参数）：

| 步骤 | 浮点操作量级 | 备注 |
|---|---|---|
| 参考子集 Hessian（逆合成，每 POI 一次，全序列复用） | ~961 × 12 × 12 ≈ 1.4×10⁵ FLOP | **摊薄到整个序列，可忽略** |
| 每次 ICGN 迭代 | 插值 961 点（双五次 ≈ 36 乘加）+ ZNSSD + 12 维雅可比投影 ≈ 961 × ~60 ≈ 6×10⁴ FLOP | 典型收敛 6–10 次迭代 |
| 单次匹配（含初值） | ≈ 5×10⁵ FLOP | |
| **每 3D POI 每帧** | 立体匹配（参考帧摊薄）+ 两视图时间匹配 ≈ **1.0×10⁶ FLOP** + 三角化 ~10³ + 应变 ~10³ | |

**硬件对照**

| 平台 | 峰值 FP32 | 实际可达（存储受限，取 15–25%） | 理论 3D POI/s |
|---|---|---|---|
| 32 核 CPU，AVX-512 | ≈ 3 TFLOPS | ≈ 0.6 TFLOPS | ≈ 6×10⁵ |
| 16 核 CPU，AVX-512 | ≈ 1.5 TFLOPS | ≈ 0.35 TFLOPS | ≈ 3.5×10⁵ |
| 单张现代消费级 GPU（约 40 TFLOPS FP32 级别） | 40 TFLOPS | ≈ 8 TFLOPS | ≈ 8×10⁶ |

**HL3-3D 承诺目标（保守取理论值的 40%，并注明测试条件）**

| 配置 | 目标 3D POI/s | 与 VIC 公开宣称对比 |
|---|---|---|
| 单 GPU（消费级），一阶形函数，子集 21 | **≥ 3×10⁶** | VIC 宣称 32 核 CPU 1×10⁶ 点/s（且未注明是 2D 点还是 3D 点、几阶形函数、子集多大）→ **≥ 3×** |
| 单 GPU，二阶形函数，子集 31 | **≥ 1×10⁶** | 在**更严格的条件下**打平 VIC 的数字 |
| **16 核 CPU（无 GPU）**，一阶，子集 21 | **≥ 5×10⁵** | 用一半核心达到 VIC 一半吞吐，性价比 ~1:1，证明 CPU 路径不是摆设 |
| 32 核 CPU，一阶，子集 21 | **≥ 1×10⁶** | 同核数打平 |

**这里的产品叙事不是"我更快"，而是"我把条件说清楚了"。** VIC 的 1e6 点/s 是没有注明子集大小、形函数阶数、是 2D 还是 3D 点、是否含应变的营销数字。HL3 的每一个吞吐数字都附带完整的 `benchmark_manifest.json`（图像尺寸、子集、步长、形函数阶、收敛判据、硬件型号、驱动版本、是否含应变与不确定度），并提供一键复现脚本。**可复现的诚实数字，对工程客户比一个大数字更有说服力。**

### 11.3 GPU / CPU 混合策略

```
┌─ 采集线程 ──► 环形缓冲（pinned host memory）
│
├─ 上传流（CUDA stream A）：H2D 异步拷贝，与计算重叠
│
├─ 预处理核（GPU）：去噪 → B 样条预滤波系数（一次，缓存到全局显存）
│
├─ 整像素核（GPU）：
│    · 首帧：FFT-CC（cuFFT 批处理）或 SIFT 特征引导仿射
│    · 后续帧：上一帧结果 + 全局仿射预测（几乎零成本）
│
├─ ICGN 核（GPU，性能核心）：
│    · 一个 warp（32 线程）处理一个 POI，子集像素在 warp 内分摊
│    · 参考子集梯度与 Hessian 逆预计算，常驻 shared memory / L1
│    · warp 内归约用 __shfl_down_sync，无 shared memory bank conflict
│    · 图像走纹理内存（硬件双线性作 B 样条求值的构件）
│    · 累加用 FP32 图像 + FP64（或 Kahan）累加 Hessian/ZNCC，保精度
│    · 收敛的 POI 提前退出，用 warp ballot 做负载压缩，避免长尾
│
├─ 立体匹配核（GPU）：极曲线一维搜索，与时间匹配核共用 ICGN 实现
│
├─ 三角化 + 协方差核（GPU）：每点 3×3，纯并行
│
├─ 应变核（GPU）：kd-tree 邻域预建（CPU 一次）→ GPU 上做小规模加权最小二乘（每 POI 一个 6×6 或 12×12 正规方程，Cholesky）
│
├─ 融合/位姿图/FEA 投影（CPU）：问题规模小，用 Eigen + 稀疏求解
│
└─ 可视化：GPU 缓冲零拷贝交给渲染器（CUDA-GL / CUDA-Vulkan interop），避免回传主机
```

**后端抽象**：核心算子写一次，经薄抽象层落到 CUDA / HIP（AMD）/ SYCL（Intel）/ wgpu-compute（跨平台兜底）/ CPU SIMD（xsimd 或 std::simd）。**跨平台是对 Windows-only 的 VIC 的正面攻击**，但只有当 Linux/macOS 路径性能不掉队时才成立——因此 CPU SIMD 路径必须认真做，不能是"能跑就行"的参考实现。

**GPU/CPU 数值一致性契约**：同一输入、同一参数，GPU 与 CPU 结果的位移差 ≤ 1e-4 px，应变差 ≤ 1 µε。CI 中对每个提交跑一致性回归。这条是计量溯源的硬要求，也是"开源可审计"叙事的支点。

### 11.4 IO 与内存

- 图像不全量入内存：mmap + 分块 LRU；序列长度不受 RAM 限制。
- 结果流式写入 HDF5/Zarr（分块 + 压缩，blosc/zstd），支持边算边看。
- 16 相机高速场景：每系统独立 pipeline，NUMA 亲和绑定，避免跨 socket 内存流量。

## 12. S10 FEA 对比与模型验证

VIC 的公开叙事是"iris 里能导入 FE 数据做可视化对比"。EikoSim/MatchID 在这条线上更强。HL3 的目标不是追平"能画差异图"，而是做到 **带不确定度的统计化模型验证**。

### 12.1 网格与结果导入

| 格式 | 来源 | 优先级 |
|---|---|---|
| Exodus II | Sierra / Cubit / DICe 生态 | P0 |
| VTK / VTU / PVD | ParaView 生态、通用 | P0 |
| Abaqus `.inp` + 结果（`.odb` 经 `abaqus python` 导出，或 `.fil`/`.rpt`） | 工业主力 | P0 |
| Ansys（`.rst` 经 PyDPF / pyansys；MAPDL `.cdb`） | 工业主力 | P1 |
| Nastran `.op2` / `.bdf` | 航空 | P1 |
| Gmsh `.msh`、通用 `.unv` | 学术 | P1 |
| OBJ / STL / PLY（仅几何） | 与 VIC-2D 8 的"工程网格导入"对齐 | P0 |

导入后统一为内部 `SurfaceMesh + NodalField/ElementField` 结构（共享内核，见 R1-O3）。**只需要 FE 模型的自由表面**——自动抽取外表面并保留到体单元的映射。

### 12.2 配准（DIC 世界系 ↔ FE 模型系）

1. **粗配准**：三点对应 / 基准点 / PCA 主轴 / 用户手动 6-DOF 拖拽（带实时残差显示）。
2. **精配准**：点到面 ICP，**尺度锁定为 1**（DIC 与 FE 都在物理单位下，允许尺度自由是掩盖标定错误的常见陷阱）。
3. **配准自由度可约束**：只允许绕某轴旋转、只允许沿某面平移等（试样有对称性时避免滑移）。
4. **配准残差进入误差预算**：`Σ_total = Σ_DIC + Σ_FE(可选) + Σ_registration`。配准本身的不确定度由 ICP 的 Hessian 给出。
5. **配准诊断**：若配准残差场有系统性结构（如整体弯曲），提示"FE 几何与实物几何不符（制造偏差 / 装配），而不是变形不符"——这是工程上极有价值但常被混淆的区分。

### 12.3 双向投影

| 方向 | 做法 | 何时用 |
|---|---|---|
| **DIC → FEM**（把测量投到网格） | BVH 加速最近点投影到单元表面 → 重心坐标插值 → 得到节点/积分点上的实测值；对稀疏区用移动最小二乘（MLS）外推并标记外推区 | FE 团队要在自己的后处理里看实测；做 FEMU/参数反演的输入 |
| **FEM → DIC**（把仿真投到测点） | 在每个 DIC POI 的 3D 位置上用 FE 形函数求值 | 保持 DIC 的空间分辨率与不确定度不被网格插值污染；**默认方向** |
| **双向都做并交叉检验** | 两个方向的差异图应一致；若不一致 → 网格太粗或 DIC 太稀 | 质量自检 |

**关键细节：必须对 FE 结果施加与 DIC 相同的空间滤波。** DIC 的应变经过 VSG 窗平滑，FE 的应变没有。直接比较是不公平的，会把 DIC 的平滑误认为"模型偏差"。HL3 自动对 FE 场施加等效 VSG 算子（同样的邻域拟合），并在报告里显式声明"已施加等效 VSG = N 点"。**这一点是很多对比工作的系统性错误，做对了就是可宣传的技术正确性。**

### 12.4 差异量与验证判定

- 逐点差 `Δ = q_DIC − q_FEM`（q 可为 U/V/W、形貌 Z、E_xx/E_yy/E_xy、主应变、等效应变）
- 场级：RMSE、MAE、P95、归一化 RMSE（除以场的量程或 P95）、相关系数、Bland–Altman 图
- **归一化残差 `z = Δ / sqrt(σ²_DIC + σ²_reg)`**：这是核心增值。z 场的可视化 + 直方图 + "落在 |z| < 2 的点占比"。
- **验证判定（ASME V&V 10 / V&V 20 风格）**：给出"在 95% 置信水平下，模型与实验在 X% 的测点上不可区分；不可区分区域集中在 …；显著偏离区域为 …"。输出结构化的 `validation_report.json` + PDF。
- 与逆问题挂钩（Round 2/3）：FEMU（有限元模型更新）与 VFM（虚拟场法）的接口预留，用带协方差的 DIC 数据做加权最小二乘参数辨识——这是 MatchID 的强项叙事，我们要在开源可复现上超过它。

```
    /strain          E_xx,E_yy,E_xy,E1,E2,θ,E_eq + Σ_E + VSG 尺寸

/fea                 导入网格、配准变换、投影场、Δ、z、验证判定
```

**导出**：CSV / TSV、VTK/VTU（含所有场与不确定度，直接 ParaView 打开）、Exodus、STL/PLY/OBJ（形貌）、MATLAB `.mat`、NumPy `.npz`、Parquet（大数据分析）、图像序列/视频。

**Python API（Python-first，不是事后脚本）**：`hl3.stereo` 模块，pybind11 绑定，与 vicpyx 的定位对标但**在库外也能独立使用**（不需要打开 GUI 工程）。所有 GUI 能做的事都有 API；GUI 操作可录制为 Python 脚本（"Copy as Python"）。

### 14.2 合成散斑渲染器（自研，`hl3-synth`）

对标 Challenge 使用的 Balcaen 模拟器（KU Leuven，独立于所有商业厂商）的**功能定位**，但完全独立实现：

- 输入：三角网格几何（或解析曲面）+ 位移场（解析或来自 FE）+ 散斑纹理（程序生成或真实散斑图映射）+ 相机模型（含畸变）+ 光照。
- 渲染：超采样（≥16×）+ 精确面积积分抗锯齿（不是简单点采样），确保亚像素真值精确；加入可控的传感器噪声（散粒噪声 + 读出噪声 + 固定图案噪声）、量化、镜头模糊 PSF。
- 可精确控制的误差注入：纯亚像素平移（扫相位测 PIB）、纯离面平移、纯刚体旋转、已知应变场、已知曲率、遮挡、局部失焦、光照漂移、热浪扰动。
- **这是唯一能给出精确真值的手段**，是所有算法级验收的基础。

### 14.3 分层测试矩阵

| 层 | 测试 | 判据 |
|---|---|---|
| **T0 单元** | 三角化闭式解 vs 解析真值；Umeyama vs 已知 R,t；应变算子 vs 解析梯度；畸变正反映射往返；极曲线采样精度 | 数值误差 ≤ 1e-10（双精度）；覆盖率 ≥ 90% |
| **T1 合成 · 亚像素相位扫描** | 0.0→1.0 步进 0.05 的纯平移，测 PIB | 补偿后 PIB 峰峰 ≤ 0.005 px；未补偿值一并报告 |
| **T2 合成 · 噪声底** | 静止序列（仅传感器噪声），50 帧 | 位移 σ ≤ 0.01 px（子集 31，一阶）；3D 位置 σ 与理论传播值吻合 ±20% |
| **T3 合成 · 已知形状板** | 复现 Challenge Sample 1 的几何（三角棱 45°、两个半圆柱、抬高台阶），自渲染 | 形貌误差 ≤ 15 µm（合成，无实验误差）；边缘覆盖率 ≥ 95% |

| **T7 实测 · Stereo Challenge Sample 1（16 mm & 35 mm）** | 复现论文对比协议（论文附带 MATLAB 对比脚本可下载） | 达到 §1.2 全部目标 |
| **T8 实测 · Sample 2（仿真平移，双镜头）** | 同上，纯软件误差 | 误差应显著小于 T7（无实验误差），差值即实验误差估计 |
| **T9 实测 · Sample 3/4（D 形试样拉伸，实验 + FE 仿真）** | 全场位移与应变；Sample 4 有 FE 位移场作真值 | **同时验证 §12 的 FEA 对比链路** |

### 14.4 三角化 moiré 的定量检验

对 T7/T8 的位移残差场（去除刚体运动后）做 2D FFT：
- 计算功率谱，剔除低频（真实变形）分量；
- 检验是否存在超过背景 5σ 的孤立峰；
- 判据：**无显著峰 = 通过**。这个检验直接对应 Challenge 中 Group 2 的 moiré 问题，是一个可以公开宣称"我们没有这个问题"的具体技术点。

### 14.5 对外发布纪律

- 所有基准结果附 `benchmark_manifest.json`（完整参数 + 硬件 + 版本 + 数据集哈希）与一键复现脚本。
- 与 Challenge 论文对比时，**只引用论文中已公开的匿名分组数字**，不做"我们打败了 VIC"这类点名对比（论文本身是匿名的，点名是不诚实的）。正确表述："在 iDICs Stereo-DIC Challenge 1.0 上，HL3-3D 的最大绝对位移误差为 X µm，优于该 Challenge 论文中五个参赛商业码公开报告的 ±80 µm 上界。"
- 鼓励第三方复现；把我方结果提交给 iDICs 参与后续 Challenge。
