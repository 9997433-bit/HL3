## 1. "超越"的判定公式不变，路线图 = 按 A → C → B 的次序关闭它

R2-F1 §2 已冻结（推翻需书面 ADR，本文不推翻）：

> **超越成立 ⇔ A 组（精度平权）6 项全 PASS ＋ B 组（显著优势）≥4/6 PASS ＋ C 组（独有能力）全 PASS**，每项附第三方可复算证据包。

排序原理（这是本文的核心主张）：

1. **A 组先行**——精度平权是入场券，全部可在本环境 + 公开数据上闭合，不依赖任何硬件。
2. **C 组紧随**（可复现性/UQ 默认化/开放 schema）——纯计算与规范工作，同样不依赖硬件，而且是 VIC 商业模式结构性难以跟进的信任资产（R1-F3 楔子 #3/#5/#10）。
3. **B 组分两批**：B3（TTFR）、B4（跨平台）、B5（GPG 内建）、B6（FEA 闭环）四项**不需要 GPU 也不需要相机**，云 CI 与本环境即可闭合；B1（吞吐）、B2（实时）依赖外部 GPU 基准机与硬件在环实验室。**因为 B 组只要求 ≥4/6，"软件可达的四项"先闭合即可使超越公式在纸面成立；B1/B2 随后把"有保留的超越"升级为"无保留的超越"。** 这是整条路线图对硬件依赖做的最重要的解耦。

禁止事项随行：任何阶段都不得产生"比 VIC 快 X 倍"（RUL-03）、"对齐 VIC UI"（RUL-06）、显微镜能力（RUL-04）表述。

## 3. 各阶段详表

### S1 · 内核计量收口（P1/P2 残项；R2-F1 §4 的 G1/G6/G10）

**目标**：把 2D 内核从"合成平移 8×10⁻⁴ px"推进到 A 组 v1 门槛，并冻结 schema 1.0。

- 工作项：二阶形函数；双三次/双五次 B 样条统一（Keys 双三次已实测未过 S 曲线门，见 R2-G2 §3——默认插值定为 B 样条并回归锁定）；FFT-CC 初值 + HYBRID 路径；应变引擎（切窗 PLS、VSG 可配、Green-Lagrange 族）；G2 全量矩阵由**稳定 ICGN API**复跑（不再用标量 stub）；2D Challenge 精选子集下载 + SHA-256 manifest（预算内，Challenge 数据不入 git）；schema 0.x→1.0 冻结评审。
- 出口证据：A1 σ_u ≤0.01 px（带噪静态，≥3 套散斑平均）；A2 S 曲线峰峰 ≤0.01 px；A4 应变噪声底 ≤100 µε（声明 VSG）；`benchmarks/metrology/metrics.json` 由脚本判定 pass/fail；schema 1.0 冻结声明 + 迁移测试。
- 风险：插值收口不达标 → 按 RUL-07 纪律 xfail 登记数值差距，禁止放宽门槛。

### S2 · 立体链路闭环（P3）

**目标**：从"标定+三角化原型"到"图像进、3D 位移/曲面应变出"的完整立体链。

- 工作项：极线约束 ICGN 立体匹配（二阶形函数默认）；时序匹配 → U/V/W；切平面曲面应变；标定升级（全参数光束法平差 + bootstrap 参数协方差 + 逐图残差落盘，O2 契约）；四路闭环自检；Stereo Challenge Sample 1（35 mm 组）端到端；刚体协议合成孪生版。
- 出口证据：A6 标定 RMS ≤0.03 px 且极线误差 ≤2× 标定分数；A5 ±20 mm 行程 3D 误差 ≤80 µm（Stereo Challenge 官方流程）；A4(3D) σ_ε ≤100 µε；离面平移伪应变 ≤50 µε（合成孪生）。
- 诚实标注：**立体精度上限在标定而非相关器**（Stereo Challenge 1.0 公开结论，R1-F4 R-01 最高风险）。物理刚体/平移台实测挂"线下实验室"标签，合成孪生先行——这不是回避，是本环境的物理事实。

### S3 · C 组能力默认化（P7 计算部分前移，与 S2 并行）

**目标**：把三项独有能力从"字段与规格"做成"默认打开的产品行为"。C 组不依赖硬件，却是竞品结构性追不上的差异化，**前移零代价、收益最大**。

- 工作项：C1——确定性模式（固定/跨线程数一致）、工程文件强制含参数快照 + 图像哈希、异机复算差异报告脚本；C2——图像噪声→位移协方差→应变 CI 端到端传播，≥1000 次蒙特卡洛交叉验证，95% CI 实证覆盖率测试（目标 ∈ [90%, 98%]），标定协方差接入（依赖 S2 的 bootstrap 输出）；C3——schema 一致性测试套件 + `hl3 validate` + 纯 h5py 参考读取器（无 HL3 亦可读全部结果）。
- 出口证据：C1/C2/C3 各自的 Gate 工件（R2-F1 §2 C 组表）；UQ 白皮书初稿（全文献引用）。

### S4 · 无头产品链 + GUI 基线（P2 收口 + P6 无头部分）

**目标**：任何人 `pip install hl3` 后 15 分钟内拿到第一张带不确定度的应变云图——不需要 GUI 也能走完全链，这本身就是对 VIC 分发摩擦的结构性打击。

- 工作项：CLI 全链（`hl3 run / sweep / doctor / report`）；Python API v2（采集回放→相关→应变→UQ→出图全脚本化）；无头渲染（CLI/Python 出版级出图，VIC 公开叙事以桌面为主——结构性超越点）；FEA 闭环 v1：FE 网格导入（VTK/Exodus）+ DIC↔FE 双向投影 + **同滤波链（等效 VSG）对比**报告 + 实测边界条件导出（B6 门槛即此，全局 FE-DIC 按 RUL-05 留 v1.x beta）；GPG 报告 lint（缺字段拒绝出报告，B5）；社区版 GUI 基线（基础查看器 + AOI 编辑，明确不是 iris 级）；三平台 CI 矩阵点亮（B4 起步：Linux/Windows/macOS 全绿 + 数值一致 <1e-6）。
- 出口证据：B3 脚本化秒表 + 录屏（对照事实：VIC 公开评估流程为 Windows 安装包 + PC 专属密钥 + 销售跟进，只作事实陈述不作贬损对比）；B5 报告 lint 强制生效；B6 开孔板 DIC vs FEA 对照案例一个 Python 脚本复现；三平台 CI 全绿。
- **此门通过时，超越公式的 B 组已有 4/6 在望，且全部不依赖 GPU/相机。**

### S5 · GPU 吞吐（P4 计算部分；场所=外部固定基准机）

**目标**：兑现 RUL-03 冻结目标表——32 核 CPU ≥1×10⁶ POI/s（v1 Gate）、单消费级 GPU ≥5×10⁶ POI/s（SOTA）、3D ≥3×10⁶ 3D-POI/s，全部按 G2 §7 计时边界 + manifest 发布。

- 前置：parity 测试床先于任何 GPU 优化合入（通用档 ≤1e-4 px；计量档 ≤1e-6 px，RUL-08）；CPU float64 永远是规范实现（RUL-02）。
- 出口证据：parity 报告全量逐点统计入档；吞吐表（≥2 档 GPU + 32 核 CPU）+ `benchmark-manifest.json` + 一键复跑；每条数字带四档计时边界之一。
- 诚实标注：**本环境 4 vCPU 无 GPU，此阶段整体发生在外部固定基准机上**；在那之前一切吞吐目标仍是"协议绑定目标"，不是成绩。"比 VIC 快"在满足 G2 §7.3 同机四条件前永久禁言。

### S6 · 采集 + 实时（P5 + P4 实时部分；场所=硬件在环实验室）

**目标**：把"分析软件"补成"测量链"——这是 VIC 家族（VIC-Snap/VIC-Gauge）真正的产品形态。

- 工作项：GenICam/GenTL 抽象层（Mock 生产者已在仓库，是 CI 永久基座）；≥2 家厂商 SDK 适配（每家过 ADR-LIC-001 式许可审计）；软/硬触发抽象 + 双目同步性度量 + 时戳体系；高速落盘（环形缓冲→HDF5 分块，掉帧统计）；实况散斑质量反馈 + 标定采集助手；实时 Gauge：取帧→ROI 相关→虚拟应变片输出，实时与离线**同代码路径同结果**。
- 出口证据：Mock 注入（掉帧/抖动）集成测试常绿；实机冒烟清单（≥2 厂商）；B2 点测端到端延迟 <10 ms @ 1 kHz、全场 ≥25 fps @ 10⁴ POI（5 MP 流）+ 24 h 浸泡无漂移；同步性测量报告。
- 诚实标注：实机矩阵是**发布门**而非开发门；没有实验室以前，本阶段只能推进到 Mock 全绿 + 接口冻结。相机 SDK 生态碎片化是 R1-F4 R-03 高风险项，靠抽象层 + 插件隔离对冲。

### S7 · Challenge 领跑（P7 完成；依赖 S1+S2+S3）

**目标**：用公开、可复算的第三方基准建立话语权——这是对"25 年品牌"唯一诚实的正面攻击方式。

- 工作项：2D-DIC Challenge 1.0/2.0 全量指标复跑（Star 图 MEI、噪声底、Sample 系列）；Stereo Challenge 全流程（含 16 mm 大畸变组）；每项成绩附**一键复现包**（数据 manifest + 环境清单 + 脚本 + metrics.json）；与已发表曲线同图（用各榜单官方口径，L10%/L20% 按 RUL-08 纪律）；结果公开发布 + 参与 iDICs 社区基准共建。
- 出口证据：A3 MEI 不劣于 Challenge 2.0 主流软件中位数（v1）/ 进入已发表第一梯队（SOTA）；复现包经干净环境第三方复跑成功记录；成为**已发表结果表中唯一自带一键复现包的实现**（C1 的话语权变现）。
- 诚实标注：与 VIC 现版本的直接对比永远只能引用已发表第三方数字或下届 Challenge 公开排名（GAP-4）；成绩不及预期时差距回灌 S1/S2 数值清单，禁止只调参不留证据。

### S8 · 跨平台安装器与产品化（P9）

**目标**：把"仓库"变成"产品"：三平台签名分发 + 自助评估 + 支持基础设施。

- 工作项：Windows MSI/MSIX、macOS 公证 dmg、Linux 包 + 容器镜像 + 离线介质；自动更新通道；自助评估零人工介入（对打 VIC 公开评估流程摩擦点的硬性验收项）；付费模块许可系统（浮动/离线激活——注意：**开源内核与社区版永远无许可组件**，许可系统只服务 §8.3 付费层，别重蹈对手覆辙）；文档体系（理论手册逐算法文献引用）；崩溃报告与诊断包；SBOM + 第三方声明 + 签名流水线；发布演练。
- 出口证据：三平台干净虚拟机"安装→跑黄金工程→卸载"全流程自动化；B4 定档（三平台同日发版 + 数值一致）；SBOM 审计通过（R3-G1 已给出声明级底稿）；发布核对单 + 回滚预案。

| 跨平台安装器 | Windows-only + PC 密钥 + 销售跟进 | 三平台签名安装 + `pip install hl3` + 自助评估零人工介入 | S4 起步，S8 定档 | 低：CI runner + 签名证书/公证账号 |

## 5. 硬件与支持护城河：诚实评估（本文最重要的一节）

`research/vic_public_feature_baseline.md` 列出的护城河必须逐条直视，不许用"我们软件更好"糊弄过去：

| # | 对手护城河 | 我们能不能正面攻 | 应对 |
|---|-----------|------------------|------|
| 1 | 25+ 年算法与应用经验、Sutton 系创始团队品牌、iDICs 生态话语权 | **不能**。品牌与信任以十年计积累，没有任何工程手段短路它 | 唯一诚实路径是 S7：公开 Challenge 成绩 + 复现包 + 开源可审计内核，让第三方证据替我们说话。这是慢变量，接受它 |
| 2 | 交钥匙硬件（相机/镜头/照明/标定板/散斑套件、Blue Hawk 级系统） | **不正面攻，永不自造硬件**（R2-F3 §6 冻结） | 认证硬件清单 + GenICam 标准路径 + 靶标生成器开源（`hl3-target`）；"用你现有的相机达到已知精度等级"本身是对交钥匙模式的错位打击，但**对"要一站式交付"的客户，我们在可见的将来就是不如它省心**——这句话要敢写进销售话术的反面清单 |
| 3 | 采集软件与相机 SDK 深度集成 | 部分能攻 | GenICam 覆盖主流工业相机；厂商私有 SDK 深度特性逐家谈授权进 Capture Pro；高速相机（Photron/Phantom 级）适配没有硬件就没有进度，实机矩阵是发布门 |
| 4 | 工业支持、培训、认证体系 | **短期不能**。支持组织 = 真人 + 响应 SLA + 领域口碑，这是组织建设问题，完全在代理/代码能力之外 | 先用"可复现证据包 + 开放 schema + 文档体系"降低支持需求本身；商业化后按付费层建支持团队；在此之前**不对工业客户承诺 SLA** |
| 5 | Windows 桌面工作流打磨（报告、复制粘贴、模板、UX 细节） | 未知域（RUL-06）：我们从未合法见过其 UI | 不模仿、不猜测；以 iDICs 工作流 + 用户访谈第一性设计；持证用户 Windows 走查协议移交用户侧（GAP-1）。GUI 打磨需要 beta 用户迭代回路——这个回路今天不存在，列为 S8 之后的持续工作流而非一个可关闭的门 |
| 6 | 存量装机与数据锁定（.z3d 等专有工程格式） | 不逆向（LEGAL.md 红线） | 只支持其公开导出格式（CSV/ASCII）迁移；开放 schema 让"进来容易出去也容易"成为我们的卖点而不是话术 |

**一句话总结**：我们能在**软件测量链 + 公开基准 + 分发体验**上超越；我们在**硬件交钥匙、支持组织、品牌年头**上就是落后的，且这三样不因代码质量而改变。任何对外叙事把后三样含糊掉，按 R2-F4 L-6 声明造假处理。

## 7. 熔断与改道判据（防止路线图变成信仰）

1. **A 组任何一项在 S1/S2 出口反复不过** → 冻结下游 S4 之后的新功能线，数值问题回灌内核（R1-F4 铁律"计量优先于功能"）；xfail 登记，禁止放宽门槛。
2. **GPU parity 计量档（≤1e-6 px）实测不可达** → 计量模式永久锁 CPU（RUL-02 本就如此），GPU 只服务吞吐与实时叙事；不追加"GPU 也是计量级"的宣称。
3. **Challenge 成绩落在已发表第一梯队之外** → 不发布"超越"表述，把 MEI/噪声底差距逐项开缺陷单回 S1/S2；复现包照发（诚实本身是资产）。
4. **相机 SDK 授权谈不下来或实验室长期缺位** → B2 降级为"Mock 验证 + 接口冻结"，超越公式走 B3/B4/B5/B6 四项路径（§1 的解耦正是为此留的），对外表述相应降格为"软件链超越，实时能力待实机验证"。
5. **任何阶段出现 L 系列一票否决命中**（VIC 二进制、OpenCorr 拷贝、显微镜实现、无协议吞吐宣称）→ 全线停工先修法务，无例外。
