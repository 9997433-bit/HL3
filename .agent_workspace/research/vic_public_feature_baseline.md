# VIC-2D / VIC-3D 公开功能基线（非逆向）

信息来源：correlatedsolutions.com 产品页、systems 页、downloads 页、VIC-2D 8 / VIC-3D 11 发布说明。  
本文件只记录公开营销与规格，用于竞品差距分析。

## 产品家族

| 产品 | 维度 | 公开版本 | 角色 |
|------|------|----------|------|
| VIC-2D | 单相机平面内 | 8（iris） | 平面试样全场位移/应变 |
| VIC-3D | 立体双目表面 | 11.4 | 三维形貌、位移 U/V/W、应变 |

| vicpyx | Python 扩展 | VIC-3D 11 | 项目内脚本、派生量、导出 |

## VIC-2D 8 公开能力

- 平面内全场位移与应变；应变约 50 µε ~ >2500%；亚微米位移（依赖视场）。
- 运动分辨率宣传：1/100 像素。
- 应变计算可无标定（2D 常见）；试样从纳米到 >100 m（换光学）。
- 显微镜/SEM 模块；刚性运动去除；面内转角；自定义变量公式。
- 自动起点检测；AOI 编辑器；模拟量同步采集。
- 导出：CSV / STL / ASCII / MATLAB 等。
- **v8 新点**：Python 扩展、实时 2D 分析（需许可）、命令行批处理、模板报告、FFT/FRF、HDF5、虚拟应变片（VSG）、工程网格导入（OBJ/STL/PLY）、暗色主题、iris 绘图模板。

## VIC-3D 11 公开能力

- 任意曲面三维位移；应变 50 µε ~ 2500%+；应变分辨率宣传 10–50 µε。
- 试样 <1 mm ~ >100 m；动态最高宣传 5,000,000 fps（取决于相机）。
- 立体标定后测量；不受大刚体位移影响。
- 吞吐宣传：单 32 核 CPU 可达 1,000,000 点/秒；强调实时。
- FEA 与 DIC 对比工作流；浮动/网络许可；Windows。
- **vicpyx**：内置扩展库 + 用户脚本；结果写回工程。
- **iris**：FEA 导入、模拟量叠加、运动模糊动画、散斑贴图、等值线、4K/PDF 出版图。
- **配套系统**：准静态高分辨率、高速、超高速、FFT 振动 ODS、红外温度+应变、立体显微镜（专利畸变校正）、最多 16 相机多系统拼接、剪切散斑、Blue Hawk / Blue Falcon 硬件。
- **模块**：疲劳/振动相位触发、VIC-Gauge 实时、全场实时。
- **DMT**：圆形/四分标记点跟踪（碰撞/土木）。

## 必须看清的护城河（软件之外）

1. 25+ 年算法与应用经验、Sutton 等创始团队品牌。
2. 交钥匙硬件（相机、镜头、梁、照明、标定板、散斑套件）。
3. 采集软件与相机 SDK 深度集成。
4. 工业支持、培训、认证与 iDICs 生态话语权。
5. Windows 桌面工作流（报告、复制粘贴、模板）。

要“超过”它们，不能只做一个相关器 demo，必须把 **测量链完整性、不确定度、实时、可视化、自动化、跨平台与可重复科学** 做成产品。

## 公开短板（可攻击点，基于公开信息推断）

- **Windows-only** 分析软件。
- 许可与评估流程重（PC 密钥、销售跟进），研究组/初创部署摩擦大。
- 局部 subset DIC 为主，点云到 FE 网格需后处理（EikoSim 等以此差异化）。
- 核心相关器闭源，无法做可重复计量溯源到源码。
- 价格与交钥匙绑定，软件单独扩张受硬件销售模式约束。
- 深度学习匹配、自适应网格、开源插件市场不是其主叙事。
